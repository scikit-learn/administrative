### Array API: classifiers with string labels

Arthur Lacote raised the difficulty of supporting classifiers with string
target labels under the Array API. Full on-device computation requires label
encoding to remain on the device, but validation is complex and currently
requires an initial NumPy round-trip before the data can be moved to the
accelerator. A follow-up PR to add **common tests for classifiers and
classification metrics** is planned, with the goal of ensuring consistent
label-encoding behavior (integer, boolean) that keeps computation on-device.
